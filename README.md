# Land Acquisition System

A web-based system to manage and digitize the land acquisition process — including landowner records, acquisition requests, approval status, and compensation tracking.

## Features
- Landowner and land record management
- Acquisition request submission & tracking
- Approval/rejection workflow
- Compensation details tracking

## Tech Stack
HTML, CSS, JavaScript, PHP, MySQL

## How to Run
git clone https://github.com/sunanda-13/landAcquisition1.git
cd landAcquisition1
